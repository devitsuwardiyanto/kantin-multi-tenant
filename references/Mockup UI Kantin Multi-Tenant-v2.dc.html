MOCKUP UI · HI-FI

Sistem Aplikasi Kantin Multi-Tenant

Mockup antarmuka berdasarkan SRS versi 1.1 (ISO/IEC/IEEE 29148:2018), dikelompokkan per kelas use case: Pelanggan, Pembayaran, Tenant, dan Pengelola Kantin. Baseline implementasi: Laravel 13 · PHP 8.3+ · Blade · Livewire 4 · Reverb · MariaDB · Redis.

ASUMSI
Data fiktif: Kantin Teknik — Universitas Nusantara, 4 tenant. Bahasa Indonesia, mata uang Rupiah, pajak 10% + biaya layanan Rp2.000.
PERANGKAT PER AKTOR
Pelanggan: ponsel (mobile-first, tanpa aplikasi). Tenant: tablet 10" (KDS, target sentuh ≥44px). Pengelola: desktop (peramban).
CAKUPAN
Seluruh use case ber-UI (18 layar + state penting). UC-08 & UC-10 berjalan di backend — direpresentasikan lewat hasilnya di UI.
ORDER
orders induk + tenant_orders per tenant
AKSES
TenantContext + scope + policy + scoped binding
KEUANGAN
snapshot + ledger append-only + row lock
TOKEN
Sesi anonim dan token opaque ≥128 bit

Catatan (wajib bila menolak)
Tulis catatan…
Persetujuan mengunci withdrawal, melepaskan hold, dan menulis ledger debit + audit append-only dalam satu transaksi. Proses idempoten; persetujuan bersamaan tidak dapat mencairkan dua kali.
Baseline Fase 0 selesai: struktur order lintas tenant, konteks akses, token anonim, snapshot transaksi, idempotensi webhook, ledger append-only, dan locking penarikan telah diselaraskan dengan SRS versi 1.1. Tahap berikutnya adalah implementasi vertical slice pada Laravel 13.
