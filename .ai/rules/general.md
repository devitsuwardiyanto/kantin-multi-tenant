# General

## Tema blok kode modul praktikum: Cyan Light + token VS Code (dikunci)
Semua blok kode di DOCX modul (dan modul_praktikum/*) wajib berlatar terang Cyan Light Theme (JetBrains, OlyaB/CyanTheme cyanScheme.xml), jangan pernah kembali ke latar hitam/Dark+.
Latar kode F2F3F7, label E4EAED, garis kiri B8DDE0, teks 262626. Token (kategori standar VS Code PHP/HTML/Blade, juga cmd/bash): keyword/tag/directive 000080 tebal; string & nilai atribut 00733B; angka/nama atribut/flag 0073E6; komentar & baris output `::` 808080 miring; variable/properti 660E7A; fungsi 795E26; kelas/tipe/namespace 267F99. Font Consolas 8 pt.
Tema diterapkan terakhir setelah semua perubahan konten, lalu split modul_praktikum dibuat ulang. Isi kode tidak boleh berubah karena pewarnaan.
